# Glossaire de traduction — termes français propres au jeu

Règles communes à toutes les langues :

1. **Traduire l'idée et garder le sigle entre parenthèses** à la première apparition dans un texte :
   « le salaire minimum (SMIC) ». Le sigle reste : c'est le mot que l'élève retrouvera dans l'actualité.
2. **Ne pas remplacer par l'équivalent du pays** : le jeu parle de la France. On écrit « le salaire minimum
   français (SMIC) », pas *Mindestlohn*. L'équivalent local peut être cité dans une explication.
3. **Libellés courts** (leviers, pastilles) : nom fonctionnel + sigle si utile : « CSG (contribution sociale) ».
4. **Noms propres** (lois, plans, présidents, institutions sans équivalent) : gardés tels quels, avec une courte
   précision si nécessaire (« la loi TEPA », « le plan Juppé »).
